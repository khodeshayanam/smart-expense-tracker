========================================
  راهنمای خیلی ساده اجرای پروژه
========================================

بار اول (فقط یکبار):

1. برو داخل پوشه backend
2. این سه دستور را در PowerShell بزن:

   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python seed_demo_data.py

3. برو داخل پوشه dashboard و این را بزن:
   pip install -r requirements.txt


از دفعات بعد (خیلی ساده):

1. فایل start-backend.bat داخل پوشه backend را دوبار کلیک کن
2. فایل start-dashboard.bat داخل پوشه dashboard را دوبار کلیک کن

تمام!
